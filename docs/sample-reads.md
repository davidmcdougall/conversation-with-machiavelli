# Sample reads of the English (DEC-012)

David reads each drawn pair against the Italian before v1.0 and logs it
below. `scripts/state` counts the log for the v1.0 checklist in SCOPE §4.

## The draw

Drawn 2026-11-25, before any read, with Python's `random.Random` seeded
`"cwm-v1-sample-2026-11-25"`: per book, `rng.sample` of the pairs in
`links/pairing-map.md` order, five from Book I, two from Book II, one from
Book III; then `rng.shuffle` of the remaining pairs for the reserve. Rerunning
it gives the same pairs. Do not redraw.

Sample: I.1, I.2, I.3, I.7, I.40, II.proem, II.15, III.24.

Reserve, in order (a pair is added from the top for each failing read):
I.23, I.30, I.58, I.16, II.19, I.8.

## How to read

Read the pair's English against the facing Italian, Machiavelli then
Guicciardini. A real error is a mistranslation, an omission or addition, a
dropped hedge or condition, or a glossary breach; a preference of style is
not. For each real error, the fix gets a D-number in
`apparatus/decision-log.md`. Result: `pass`, or `fixed` with the D-numbers.
