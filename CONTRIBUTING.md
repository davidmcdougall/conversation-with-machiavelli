# Contributing

Corrections and contributions are welcome through issues and pull requests at
https://github.com/davidmcdougall/conversation-with-machiavelli.

## Reporting an error

Most useful is an error in the Italian or the English. Open an issue giving the
unit and paragraph (e.g. `FG-CONS.1.12.03`, shown beside every paragraph on the
site), what it says, what you think it should say, and — for the Italian — the
witness and page that supports the correction.

## Licence of contributions

Each contribution is licensed under the licence of the file it changes, as
stated in `REUSE.toml` (summarised in `LICENSE`):

| Component | Contribution licence |
|---|---|
| Established Italian text; research and provenance data; documentation | CC0 1.0 Universal |
| English translation; editorial commentary and apparatus | CC BY 4.0 |
| Software and build scripts | MIT |

By submitting a contribution you confirm that you have the right to submit it
on those terms. You retain copyright in your original contribution unless you
expressly waive it; contributions to CC0 components are dedicated under CC0
1.0 Universal.

Do not submit third-party material, including text from Wikisource,
Palmarocchi 1933, Grayson 1965, Atkinson & Sices 2002, or any modern critical
edition (`RIGHTS_AND_SOURCES.md`).

## AI-assisted contributions

State whether a contribution was produced with generative AI, and name the
model and its identifier where known (`TRANSLATION_METHOD.md`).

## Method

`SCOPE.md` is the project's doctrine. Run `python3 scripts/validate` before
submitting changes to the text, translation or apparatus.
